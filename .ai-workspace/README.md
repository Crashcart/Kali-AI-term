# AI Workspace

**Free-form area for AI agents to work, research, and leave notes**

No rules. No structure enforced. Just organized folders for different types of work.

## Folders

- **notes/** — Raw observations, findings, analysis
- **todos/** — Task lists and work items  
- **research/** — Deep research and investigations
- **bugs/** — Bug observations before formalization
- **ideas/** — Brainstorms and concepts
- **analysis/** — Data analysis, profiling results

## How AIs Use This

1. Drop findings here as you work
2. Leave notes for the next AI
3. Organize by your preference
4. Link to main code when relevant
5. Move to formal docs/issues when ready

## What NOT to Do

- Don't delete others' work
- Don't remove findings from other AIs  
- DO add context and timestamps
- DO link to actual code locations

---

**This is scratch space. Keep good notes. Help the next AI pick up where you left off.**
