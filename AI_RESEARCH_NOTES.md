## How to Use

1. Add notes directly to this file or create sub-files as needed
2. Use clear timestamps when relevant
3. Link related findings
4. Cross-reference with formal docs when ready to formalize

**Example entry:**
```
### [2026-05-17] Terminal Performance Investigation
Noticed app slows down after 50+ commands executed.
Possible causes:
- Buffer not being cleared properly
- Output accumulating in memory
- Event listeners not being removed

Need to check: server.js lines 250-300, terminal-session.js
```
